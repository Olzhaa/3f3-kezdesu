# 3F3 жеке кездесу

3F3 тобымен 15 қазан 2026 күнгі жеке кездесулерге арналған платформа. Мұнда студенттер:
- тіркеліп, кездесу уақытын таңдайды;
- профориентация сұрақтарына жауап береді (MBTI, Гарднер, Gallup, 6 бөлім және икигай);
- мұғалімнің жазбасын және 1 жылдық жеке даму жоспарын (IDP) көреді. Әр студент тек өзінің жоспарын көреді.

Бет GitHub Pages-те тұрады, ал деректер мұғалімнің Google Sheets кестесінде сақталады.

## Іске қосу (бір рет, шамамен 10 минут)

### 1. Google Sheets кестесін ашу
1. [sheets.new](https://sheets.new) арқылы жаңа кесте ашыңыз, атын мысалы «3F3 кездесу» деп қойыңыз.
2. Мәзірден **Кеңейтімдер → Apps Script** (Extensions → Apps Script) таңдаңыз.

### 2. Серверді қою
1. Ашылған редактордағы бар кодты толық өшіріп, орнына осы репозиторийдегі `Code.gs` файлының мазмұнын қойыңыз.
2. 7-жолдағы `ОСЫНЫ-ӨЗГЕРТІҢІЗ` сөзін өзіңіздің құпиясөзіңізге ауыстырыңыз. Мұғалім панеліне осы құпиясөзбен кіресіз.
3. Сақтаңыз (💾).
4. Жоғарыдағы функциялар тізімінен `setup` таңдап, **Run** басыңыз. Google рұқсат сұрайды: өз аккаунтыңызды таңдап, **Advanced → Go to … (unsafe) → Allow** басыңыз. Бұл код сіздің кестеңізде ғана жұмыс істейді.

### 3. Веб-қосымша ретінде жариялау
1. **Deploy → New deployment** басыңыз.
2. Тісті доңғалақ белгісінен **Web app** таңдаңыз.
3. *Execute as*: **Me**, *Who has access*: **Anyone** деп қойыңыз.
4. **Deploy** басып, шыққан **Web app URL** сілтемесін көшіріңіз (`https://script.google.com/macros/s/.../exec`).

### 4. Сілтемені бетке қосу
1. GitHub-та `config.js` файлын ашып, қарындаш белгісін басыңыз.
2. `window.API_URL = "";` жолындағы тырнақшаның ішіне 3-қадамдағы сілтемені қойып, **Commit changes** басыңыз.

### 5. GitHub Pages қосу
1. Репозиторийдің **Settings → Pages** бөліміне өтіңіз.
2. *Source*: **Deploy from a branch**, *Branch*: **main**, қалта **/(root)** деп таңдап, **Save** басыңыз.
3. Бір-екі минуттан кейін сілтеме шығады: `https://<логиніңіз>.github.io/<репозиторий>/`.

## Сілтемелер
- **Студенттерге:** `https://<логиніңіз>.github.io/<репозиторий>/`
- **Мұғалімге:** сол сілтеме, соңына `#teacher` қосылады, мысалы `.../#teacher`. Кірген соң құпиясөзді жазасыз.

## Қалай жұмыс істейді
- Студент тіркелгенде оған **жеке код** беріледі. Код браузерде сақталады. Басқа телефоннан кіру үшін студент «Бұрын тіркелдім» бөліміне сол кодты жазады.
- Бір уақытқа екі студент жазыла алмайды, сервер оны тексереді.
- Мұғалімнің жазбасы мен IDP тек сол студентке, оның жеке коды арқылы ғана көрінеді.
- Кестеде парақтар автоматты түрде ашылады: `students`, `slots`, `notes`, `config`, сонымен қатар **«Жауаптар»** парағы. Онда бір студент бір жолда, бір сұрақ бір бағанда тұрады, жауаптарды Sheets-тің өзінде оқуға ыңғайлы.
- Бет 30 секунд сайын жаңарып тұрады. Мұғалім панелінде «Жаңарту» батырмасы да бар.
- Студент уақытын өзі ауыстыра алады: басқа бос уақытты басса, ескі уақыты босайды.
- Мұғалім студенттің парағын ашып, «Студентті өшіру» батырмасын екі рет басса, студент толық өшеді: тіркелуі, уақыты, жазбасы және «Жауаптар» парағындағы жолы.
- «Шығу» батырмасы студентті де, мұғалімді де шығарады. Студент шығар алдында бет одан жеке кодын сақтағанын бір рет сұрайды.

## Құпиялық туралы
- Google кестесін ешкімге бөліспеңіз: онда барлық жауаптар мен кодтар сақталады.
- `Code.gs` ішіндегі құпиясөзді ешкімге айтпаңыз.
- Студент жеке кодын басқаға берсе, сол адам оның жауаптары мен жоспарын көре алады.

## `Code.gs` кодын өзгерткен соң
**Deploy → Manage deployments → Edit (қарындаш) → Version: New version → Deploy** басыңыз. Сонда сілтеме сол күйі қалады.
